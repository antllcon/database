
Допустим, пользователь ответил на вопрос типа sequence — например,
расставил события в правильном порядке.

Вот как это хранится:
quiz_attempt_answer
Общая таблица для всех типов вопросов. Здесь хранится факт того, что пользователь ответил на конкретный вопрос
(question_id) в рамках попытки (attempt_id). Поле value — NULL, потому что для последовательности используется
отдельная таблица.

quiz_attempt_sequence

Здесь хранится порядок выбранных значений:
answer_id — ссылка на запись из quiz_attempt_answer
value_id — один из возможных элементов последовательности (из sequence_question_available_values)
position — позиция этого элемента в пользовательском ответе (например, 1, 2, 3...)

Таким образом, полный ответ на последовательный вопрос — это набор строк в quiz_attempt_sequence,
связанных по answer_id, с отсортированными по position значениями.
